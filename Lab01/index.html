Presentacion

Bienvenido este es mi portal web académico. Soy estudiante de la Escuela Profesional de Ingeniería de Sistemas de la Universidad Nacional de San Agustín de Arequipa (UNSA).

Objetivos del Curso

  • Comprender y aplicar la estructura semántica de HTML5 y los estándares de la W3C.
  • Diseñar interfaces web atractivas y adaptables utilizando CSS3, Flexbox y CSS Grid.
  • Desarrollar lógica interactiva con JavaScript y construir aplicaciones backend con Node.js y Express.

Metodología

  1. Revisión teórica: Lectura del sílabo y consulta de documentación oficial en la W3C y W3Schools.
  2. Maquetación y código: Construcción de la estructura HTML5 y estilos CSS3 en Visual Studio Code.
  3. Pruebas locales: Verificación de funcionamiento en tiempo real mediante la extensión Live Server.
  4. Control de versiones: Subida del código a repositorios para la entrega de laboratorios y trabajo colaborativo.
